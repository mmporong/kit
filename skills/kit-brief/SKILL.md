# 착수와 범위 결정

## 입력
실제 과제 안내, 제공 파일, 실행 방법, 실제 담당자 답변, 남은 시간. 없는 자료는 추측해 채우지 않습니다.

## 처리
1. 요구된 결과와 사용자 행동을 한 문장으로 적습니다.
2. 필수 조건마다 출처와 통과를 확인할 행동/값을 연결합니다.
3. 이미 확인된 것·가정·질문이 필요한 것을 분리합니다.
4. 답에 따라 구현이나 판정이 달라지는 질문만 사용자에게 제안합니다. 담당자와 대화한 척하지 않습니다.
5. 불명확한 핵심 결정은 보류하되 독립적인 기존 실행 확인 등은 진행합니다.
6. 구현과 검증을 완료할 수 있는 작은 사용자 흐름 하나부터 정합니다. 계획 문서 반복 개선에 머물지 않습니다.
7. 담당자 답변이 추가되면 바뀐 가정, 영향받는 구현과 검사만 갱신합니다.

## 출력
목표 한 문장 / 필수 조건·근거·완료 기준 / 중요한 미확정 사항 / 첫 구현 흐름.
문서 양식은 과제 지정 양식이 우선입니다. 질문 수나 기능 수를 채우기 위한 항목은 만들지 않습니다.


## 공통 경계
현재 과제 지침을 우선하고 KIT.md를 보조 원칙으로 사용합니다. 원문 데이터 보존, 외부 전송 금지, 설정 변경 금지, 미실행의 미확인 표시를 지킵니다. AI 사용 금지 단계에는 사용하지 않습니다.
