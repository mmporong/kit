# 계산 전에 데이터 의미 확인

## 입력
허용된 원본 파일, 데이터 사전, 원하는 지표/질문, 기준 문서. 원본을 수정하지 않습니다.

## 처리
1. 한 행의 의미, 개체 식별 키와 유일성 범위, 관측 시점과 값의 가용 시점을 확인합니다.
2. 파일·행·열 수와 실제 읽은 범위를 기록합니다. 일부 표본을 전체 검사로 표현하지 않습니다.
3. 식별자는 앞자리 0을 보존해 읽습니다. 숫자처럼 보여도 숫자로 확정하지 않습니다.
4. 공백/표기 차이는 후보로만 제시합니다. CH·EQP·TOOL 등 서로 다른 접두어를 제거해 동일 ID로 합치지 않습니다.
5. 결측·미측정·검사 실패·0을 구분합니다. 재검사는 행 중복이라는 이유만으로 삭제하지 않습니다.
6. 조인 전 키별 중복과 관계를 확인하고, 조인 후 행 수·미연결·수량 중복 여부를 대조합니다.
7. 지표마다 분자·분모·대상·기간·제외 조건·단위를 적습니다. 빈 데이터/분모 0은 사전 규칙 없이 0%로 바꾸지 않습니다.
8. 예측이면 예측 시점 이후 정보와 동일 개체/시간의 학습·시험 중복을 확인합니다. 전처리·임계값은 시험셋으로 선택하지 않습니다. 실제 분류·회귀 예측의 학습·평가가 필요할 때만 [모델 평가 점검](references/model-evaluation.md)을 읽고 기준선·업무 지표·평가 표본 수를 함께 확인합니다.
9. 반도체 데이터가 실제로 있을 때만 references/semiconductor.md를 읽습니다.
10. 계산은 실행 가능한 코드로 하고 작은 합성 입력/독립 산식과 대조합니다. 분석 코드의 출력 자체를 정답으로 재사용하지 않습니다.

## 출력
관측 단위·키·시간·단위 / 이상·미확정 정의 / 영향받는 범위 / 지표 산식과 실제 계산 / 제외 이유 / 한계.
모델 정확도·상관관계·집계값만으로 원인이나 운영 안전성을 확정하지 않습니다.

## 자체 합성 확인 사례
`001`을 보존하고, 전부 빈 키를 오류 없이 미확정으로 처리하며,
동일 제품의 첫 실패·재검사 성공을 기록 수와 제품 수로 구분하는지 확인합니다.
이는 실제 문제·데이터가 아니라 점검 사례입니다.


## 공통 경계
현재 과제 지침을 우선하고 KIT.md를 보조 원칙으로 사용합니다. 원문 데이터 보존, 외부 전송 금지, 설정 변경 금지, 미실행의 미확인 표시를 지킵니다. AI 사용 금지 단계에는 사용하지 않습니다.
