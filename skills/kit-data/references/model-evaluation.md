# 선택형 모델 평가 점검

실제로 분류·회귀 모델을 학습하거나 평가하는 과제에서만 읽습니다. 단순 집계·관리도·화면 수정에 모델링을 추가하지 않습니다.
이 자료는 작업 지침이며 학습 실행기, 자동 점수 판정기 또는 특정 라이브러리 설치 요구가 아닙니다.
현재 과제의 공식 지표·분할·제출 조건과 KIT.md의 권한·외부 전송 제한이 우선입니다.

## 입력과 먼저 정할 것

실제 요구, 예측 대상과 시점, 라벨 정의, 제공 데이터·공식 분할, 실제로 확인한 업무 제약을 사용합니다.
양성 클래스와 관측 단위, 예측 결과로 내릴 결정, 평가할 대상·기간을 구분합니다.
담당자에게 확인하지 않은 오탐 허용치·검토 용량·합격선을 만들지 않습니다.

## 진행

1. 예측 순간 이용할 수 있는 특징만 사용합니다. 최종 검사·수리 결과·미래 집계처럼 사후에 생기는 정보를 확인합니다.
2. 공식 분할이 있으면 먼저 따르고 의심되는 누수는 근거와 함께 표시합니다. 임의로 평가 대상을 바꾸지 않습니다.
3. 분할을 정해야 하면 실제 적용 목적에 맞춥니다. 새 개체를 평가하면 그룹을 분리하고, 미래를 평가하면 시간 순서를 보존합니다. 두 조건이 필요하면 둘 다 확인합니다. 로트·웨이퍼·반복 관측·겹치는 기간을 점검하되 회사명만 보고 특정 분할을 강제하지 않습니다.
4. 최종 시험 데이터는 특징·모델·임계값 선택에서 분리합니다. 결측 대체·정규화·인코딩·특징 선택·재표본화는 각 학습 부분에서만 적합합니다. 검증·시험에는 그때 정한 변환을 적용합니다. 시험 데이터를 선택에 썼다면 독립 최종 평가라고 부르지 않습니다.
5. 새 스택이나 AutoML을 붙이기 전에 단순 기준선을 실행합니다. 예: 분류의 다수 클래스, 회귀의 학습 자료 평균·중앙값, 적절한 단순 규칙. 선택은 과제에 맞추고 기준선도 실제로 실행합니다.
6. 후보와 기준선을 같은 평가 행·라벨·지표·운영 조건에서 비교합니다. 공식 지표를 우선하고 필요한 업무 지표를 보조로 적습니다. 임계값은 별도 검증 자료나 적절한 교차검증으로 선택한 뒤 시험에서 고정합니다.
7. 분류라면 양성 정의·혼동행렬·정밀도·재현율과 필요한 오탐률을 확인합니다. 실제 불량이 적은데 정확도만 높다고 완료하지 않습니다. 회귀라면 MAE·RMSE 등 요구 지표와 오차 단위를 함께 적습니다. 지표의 분모가 0이거나 정의되지 않는 경우는 라이브러리 출력 관례와 해석 한계를 밝힙니다.
8. 평가 행 수·개체/그룹 수·기간·클래스별 개수와 실제 오류 사례를 보고합니다. 작은 표본이나 적은 양성 수를 숨기지 않습니다. 계산하지 않은 신뢰구간·유의성·현장 개선 효과를 쓰지 않습니다.
9. 남은 시간과 자원에 맞춰 후보 수를 제한합니다. 개선되지 않은 결과도 남기고, 모델링이 요구되지 않거나 검증까지 끝내기 어려우면 불필요한 확장을 하지 않습니다.

## 분류 오류를 읽는 기준

양성을 검출 대상(예: 불량)으로 정의했다면 TP는 불량 검출, FP는 정상을 불량으로 알린 오탐, FN은 불량을 정상으로 놓친 미탐, TN은 정상 판정입니다. 혼동행렬에는 실제·예측 축과 클래스 순서를 표시합니다.
오탐 수 FP와 미탐 수 FN을 원래 건수로 보고하고, 정밀도 TP/(TP+FP), 재현율 TP/(TP+FN), 오탐률 FP/(FP+TN), 미탐률 FN/(TP+FN)의 분모를 구분합니다. 분모가 0이면 정의 불가로 표시하고 임의로 0%로 채우지 않습니다. 경보 후 검토 용량과 놓친 사례의 영향을 확인된 업무 조건 안에서 설명합니다.

## 출력

기존 기록에 다음을 필요한 만큼 남깁니다. 새 보고서 양식을 의무화하지 않습니다.

- 대상·예측 시점·양성 정의·공식 조건과 미확정 업무 제약.
- 분할 근거·평가 행/그룹/클래스 수·기간, 특징과 제외 이유.
- 기준선과 후보의 같은 조건 지표, 임계값과 그것을 정한 자료.
- 실제 실행 명령·설정·가능한 난수 seed·자료 버전·실행 시각.
- 비교 결과·오류 사례·누수 점검·한계·실행하지 못한 항목.

학습 코드 작성과 실제 학습·평가는 다릅니다. 실행하지 못했다면 성능 수치는 미확인입니다.

## 자체 합성 해석 예시

평가 자료 1,000개 중 양성이 10개이고 모든 항목을 음성으로 예측했다면 정확도는 99%지만 양성 재현율은 0%입니다.
따라서 정확도 99%만으로 불량 검출 성공을 주장하지 않습니다. 이 수치는 산식 설명용이지 실제 실험 결과가 아닙니다.
