# 제조·검사 데이터 참고 — 과제에 해당할 때만

공식 출제 내용이나 공정 규격이 아닌 일반 점검 지침입니다. 실제 문서의 정의가 우선합니다.

- 로트·웨이퍼·다이·측정 지점·검사 단계 중 관측 단위를 먼저 결정합니다.
- 식별 키는 범위를 함께 봅니다. 웨이퍼 번호만으로 모든 로트에서 유일하다고 가정하지 않습니다.
- 최초 합격률, 최종 합격률, 검사 기록별 합격 비율의 분모·재검사 정책을 구분합니다.
- 결함 사건 수와 불량 제품 수를 구분합니다. 한 제품에 여러 결함이 있을 수 있습니다.
- 장비별 비교에는 생산/검사량, 제품 종류, 기간, 검사 단계 차이를 함께 봅니다.
- 규격 한계와 공정 관리 한계는 같은 의미가 아닙니다. 관리도 신호만으로 제품 불합격이나 인과를 단정하지 않습니다.
- Cp/Cpk는 규격값·공정 안정성·분포와 변동 추정 방법 확인 없이 자동 산출/해석하지 않습니다.
- 단위·허용 범위·불량 기준을 회사명이나 상식으로 추정하지 않습니다.
- ML 과제라면 예측 시점과 라벨 생성 시점을 분리하고, 평가 목적에 맞는 시간·개체·그룹 분할을 확인합니다.
- 분석 결과는 관찰·가설·추가 확인을 구분합니다. 실제 설비 제어·공정 승인으로 확대하지 않습니다.
