# 실제 구현을 본인 말로 이해하기

## 입력
현재 코드, 확정 요구, 사용자가 실제로 한 결정, 검증 기록. 기록이 없으면 검증을 했다고 추측하지 않습니다.

## 시점 확인
사전 연습/제출 확정 전에서만 사용합니다. 제출 확정 후와 질문 생성 대기 중에는 중단합니다.
실제 금지 단계의 문항·답안·개요·첨삭·관련 코드 분석은 제공하지 않습니다.

## 처리
1. 중요한 선택 최대 세 가지를 고릅니다. 요구→선택→구현 위치→검증→한계로 연결합니다.
2. 대표 입력 하나가 처리되는 파일·함수·상태와 결과를 실제 코드 기준으로 추적합니다.
3. 실제 채택한 대안과 기각한 대안만 설명합니다. 사용자가 하지 않은 판단을 사용자의 판단처럼 만들지 않습니다.
4. 사람의 결정, AI 제안, 관찰된 결과, 아직 추론인 부분을 구분합니다.
5. 사용자가 연습을 요청하면 한 번에 질문 하나만 제시하고 답변을 기다립니다.
6. 예정된 문항을 예측하거나 가짜 모범답안·점수 향상 수치를 만들지 않습니다.

## 출력
중요한 결정 1~3개와 코드 근거 / 대표 입력의 처리 흐름 / 실제 검증 범위 / 미확인.
짧게 설명하되, 생성된 설명을 본인의 이해나 실제 동작 검증의 증거로 간주하지 않습니다.


## 공통 경계
현재 과제 지침을 우선하고 KIT.md를 보조 원칙으로 사용합니다. 원문 데이터 보존, 외부 전송 금지, 설정 변경 금지, 미실행의 미확인 표시를 지킵니다. AI 사용 금지 단계에는 사용하지 않습니다.
