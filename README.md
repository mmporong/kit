# kit

작업 범위 정리·데이터 감사·검증·디버깅·구현 설명을 위한 **선택형 Skill 5개**입니다.
정답·완성 앱·비공개 자료는 포함하지 않습니다. MCP·개인 API 키·새 모델·전역 설치가 필요하지 않습니다.

## 바로 사용하기

아래 주소는 **`mmporong/kit` 공개 저장소에 이 파일들을 게시한 뒤** 사용할 수 있습니다.
GitHub에 게시되기 전 ZIP 파일만으로 원격 clone은 되지 않습니다.

### 1. 실제 과제 폴더의 일반 터미널에서

```bash
kit_dir=$(mktemp -d) && \
git clone --depth 1 https://github.com/mmporong/kit.git "$kit_dir" && \
bash "$kit_dir/install.sh" "$PWD"
```

현재 작업 폴더를 잘 확인하세요. **준비 저장소로 이동하지 말고 실제 과제 폴더에서** 실행합니다.
스크립트를 검토한 뒤 실행하세요. 다운로드가 막히면 우회하지 마세요.

설치기는 `.agents/skills/kit-*`와 `KIT.md`만 추가합니다. 기존 `AGENTS.md`,
`AGENTS.override.md`, 소스, 설정, 모델, 권한은 바꾸지 않습니다.
같은 이름에 다른 내용이 있으면 **설치 전에 중단**합니다. 동일 내용 재설치는 재사용합니다.
Git 작업, 패키지 설치, Codex 업데이트, 네트워크 호출은 설치기 안에 없습니다.

### 2. 같은 과제 폴더에서 제공된 Codex 실행

```bash
codex
```

이미 대화가 진행 중이면 임의로 종료하지 말고 아래 파일을 명시적으로 읽히세요.
첫 요청:

> 기존 과제 지침을 먼저 읽고 KIT.md와 .agents/skills/kit-brief/SKILL.md를 참고하세요.
> 남은 시간은 ○분입니다. 필수 요구, 확인 질문, 먼저 완성할 흐름 하나를 정리하세요.
> 별도 모델·설정 변경은 하지 말고 실제 과제의 기존 환경을 사용하세요.

### 3. 필요한 상황에 하나만 사용

| 상황 | 요청 예시 | 받는 결과 |
|---|---|---|
| 처음 시작·요구 변경 | `$kit-brief 필수 조건과 첫 구현 흐름을 정리해 주세요.` | 조건·근거·완료 기준·미확정 사항 |
| 표·CSV·로그 분석 | `$kit-data 데이터의 키·단위·재검사·분모를 먼저 확인하세요.` | 데이터 감사와 계산 전 확인 사항 |
| 기능 완료·제출 전 | `$kit-verify 현재 요구 충족 여부를 실제 검사하세요.` | 통과·실패·미확인과 실행 근거 |
| 원인 모를 오류 | `$kit-debug 재현한 뒤 최소 수정과 재검증을 진행하세요.` | 재현·원인 가설·변경·재검증 |
| 제출 확정 전 복습 | `$kit-explain 대표 입력의 처리 흐름과 선택 이유를 설명하세요.` | 실제 구현 설명과 남은 한계 |

Skill 선택 문법이 지원되지 않으면 `.agents/skills/kit-data/SKILL.md`처럼
**해당 파일을 읽고 절차를 참고하라고 요청**하세요. 문서 읽기와 자동 Skill 인식은 다릅니다.
설치 완료는 파일 배치 완료일 뿐, 제공된 Codex의 자동 인식·실행 성공을 보장하지 않습니다.
인식을 위해 Codex를 업데이트하거나 관리 설정을 바꾸지 마세요.

## 최소 작업 순서

안내 읽기 → 꼭 필요한 질문 → 작은 사용자 흐름 구현 → 정상·경계·실패 검사 →
수정 후 재검사 → 선택·근거·한계 정리.

모든 Skill을 매번 실행하지 않습니다. 기본 구현은 제공된 코딩 에이전트에 맡기고,
Skill은 중요한 해석·검증의 누락을 보완할 때 사용합니다. 추가 문서 작성보다 필수 결과를 우선합니다.

## 데이터 Skill 예시 — 자체 합성 예시

A 최초 합격, B 최초 불합격·재검사 합격, C 최초 합격이라는 4개 검사 기록이라면:
검사 행 합격 비율은 3/4, 최초 합격 제품 비율은 2/3, 최종 합격 제품 비율은 3/3입니다.
어느 것을 업무상 지표로 쓸지 확인하기 전에는 하나를 임의로 '수율'이라고 단정하지 않습니다.
Skill은 데이터를 알아서 바꾸는 것이 아니라 **집계 정의와 검사 절차를 추가**합니다.

## 허용 범위와 보안

현재 과제 지침과 운영 규정이 우선입니다. 이 키트 자체가 반입 허가를 의미하지 않습니다.
공개 준비물만 허용되는 환경에서는 저장소를 요구 기간까지 공개로 유지하세요.
시험 문제·메일·개인 접속 링크·자격증명·비공개 코드·실제 제출물은 이 저장소에 넣지 마세요.
작업 중 문제·데이터·코드의 외부 전송, push, 배포, 외부 모델 연결을 하지 않습니다.
Computer Use와 브라우저 자동 조작은 사용하지 않는 보수적인 구성을 취합니다.
AI 사용이 금지되는 단계에서는 모든 Skill 사용을 중단합니다.
제출 확정 뒤 서술형 문항 생성 대기 중에도 설명·답안 생성에 이 키트를 사용하지 않습니다.

## 파일 구성

- `KIT.md`: 과제 환경에서 읽을 공통 원칙. 설치 대상.
- `skills/kit-*/SKILL.md`: 다섯 작업 절차. 설치 대상.
- `skills/kit-data/references/semiconductor.md`: 해당 데이터가 있을 때만 읽는 참고.
- `skills/kit-verify/references/evidence-log.md`: 선택적인 빈 기록 양식.
- `AGENTS.md`: 이 키트 자체를 수정하는 에이전트용 지침. 과제에는 복사하지 않음.
- `tests/test_install.py`: 설치기와 파일 구조 검사. 시험 중 실행할 필수 과정 아님.
- `SOURCES.md`: 공개 참고 출처와 범위.

## 검증과 한계

```bash
python3 -m unittest discover -s tests -v
```

검증 실행 기록은 `CHECKS.md`를 확인하세요. 이 검사는 파일 배치·충돌 방지 등을 확인하며,
실제 플랫폼 자동 인식, 모델의 지침 준수, 점수·속도·토큰 개선을 검증하지 않습니다.
이 키트에는 데이터 자동 분석 실행 스크립트가 없습니다. 분석은 제공 환경의 도구로 수행해야 합니다.
